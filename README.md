# Holbegram

Holbegram is a mobile application inspired by Instagram, developed with Flutter and Firebase.

## Description

This project is part of the Holberton School Flutter curriculum. The goal is to build a social media application that allows users to:

- Create an account
- Log in securely
- Upload images
- Store and manage user data with Firebase
- Manage media files with Cloudinary

## Technologies

- Flutter
- Dart
- Firebase Authentication
- Firebase Realtime Database
- Firebase Core
- Cloudinary

## Installation

Clone the repository:

git clone [https://github.com/Yaminadjenkal/holbertonschool\-holbegram.git](https://github.com/Yaminadjenkal/holbertonschool-holbegram.git)

Move into the project directory:

cd holbertonschool\-holbegram/holbegram

Install dependencies:

flutter pub get

Run the application:

flutter run

## Firebase Configuration

1. Create a Firebase project.
2. Enable Authentication with Email/Password.
3. Create a Realtime Database or Firestore Database.
4. Download the Firebase configuration file.
5. Place google\-services.json inside:

android/app/
